신규 서비스를 첫 커밋부터 설계해 운영까지 끌고 가는 일을 두 번 했습니다.
결제와 정산처럼 금액이 틀리면 안 되는 도메인을 주로 맡아왔고,
사고가 나면 개별 버그를 고치는 대신 같은 사고가 구조적으로 불가능해지도록 바꾸는 편입니다.

현재 모빌리티 서비스 회사에서 **백엔드 개발 파트를 맡고** 있습니다.

<br>

### 요즘 하는 일

- **Kotlin / Spring Boot** 로 배터리 교체 파트너스 플랫폼과 구독 결제 서비스를 만들고 운영합니다
- 어드민은 서버만이 아니라 **React · TypeScript 프론트까지 함께** 만듭니다
- **AI 코딩 에이전트**를 팀의 개발 프로세스에 붙여 쓰고 있습니다.
  잘 되는 것보다 어디서 사고가 나는지를 먼저 겪었고, 지금은 그걸 막는 규칙을 문서로 관리합니다

> 실무 코드는 사내 GitLab 에 있습니다. 여기 공개된 저장소는 개인 프로젝트와 학습 기록입니다.
